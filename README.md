🚀 SaaS / Tech Startup Landing Page

A premium, modern, high-conversion SaaS landing page inspired by Stripe, Vercel, Linear, and Notion.
Built with React, React Bootstrap, and Framer Motion, this project demonstrates professional frontend development with a focus on UI/UX, responsiveness, and interactive animations.

This project is frontend-only and fully production-ready, perfect for portfolios, Upwork, or client demos.

✨ Features

Hero Section with Call-to-Action
Catchy headline, subheading, primary & secondary CTAs, and animated dashboard mockup.

Features Section
Showcases 6 key SaaS features (fast performance, cloud scalability, AI-powered insights, real-time analytics, secure architecture, developer-friendly API) with icons and hover animations.

How It Works Section
3-step onboarding process with animated step cards.

Dashboard Preview Section
Admin dashboard UI with sidebar, stats cards, charts, and tables (frontend only).

Pricing Section
Monthly/Yearly toggle, 3 pricing plans (Starter, Pro, Enterprise), feature comparison, and hover animations.

Testimonials Section
User testimonials carousel with avatar, name, role, company, and feedback using dummy JSON data.

Call-to-Action Section
Strong conversion-focused message with gradient background and large CTA button.

Contact Form
Frontend-only contact form with validation and success message.

Dark / Light Mode Toggle
Smooth theme transition.

Animations & Interactions
Scroll-based animations, button hover effects, page transitions, pricing toggle animations.

Responsive Design
Fully mobile-first and accessible.

🛠️ Tech Stack

React (Vite)

React Bootstrap for layout and components

Bootstrap Utilities

React Icons

Framer Motion for animations

Dummy JSON data for pricing, features, and testimonials

Clean component-based architecture and reusable UI components
